# Pritam Biswas — Personal Portfolio

Editorial developer portfolio for **Pritam Biswas** (App & Web Developer · Competitive Programmer · AI Explorer).

## 🌐 How to View Locally

### Run with Node.js
```powershell
node server.js
```
Open your browser to: [http://localhost:3000](http://localhost:3000)

### Standalone Files
Navigate to the [portfolio/](file:///c:/Users/Pritam/Downloads/Portfolio-master/Portfolio-master/portfolio) folder and open `index.html` in your browser.

---

## 🎨 Project Structure

- **`portfolio/index.html`**: Main HTML entry point with modern metadata and semantic structure.
- **`portfolio/js/data.js`**: Profile content, technical skills, projects, achievements, and social links.
- **`portfolio/js/v3-github.jsx`**: Live GitHub activity heatmap, live stats, and pinned repositories.
- **`portfolio/js/v3-sections.jsx`**: Editorial hero, capabilities, project stack, credentials, and CV viewer.
- **`portfolio/js/terminal.jsx`**: Interactive zsh terminal console emulator.
- **`portfolio/Pritam_Biswas_CV.pdf`**: Official 2-page curriculum vitae.
- **`portfolio/photo.jpg`**: Official portrait photo.
